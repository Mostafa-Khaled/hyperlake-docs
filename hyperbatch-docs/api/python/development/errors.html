Error classes in PyHyperBatch#

This is a list of common, named error classes returned by PyHyperBatch which are defined at error-conditions.json.

When writing PyHyperBatch errors, developers must use an error class from the list. If an appropriate error class is not available, add a new one into the list. For more information, please refer to Contributing Error and Exception.

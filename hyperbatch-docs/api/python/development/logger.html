Logging in PyHyperBatch#

Introduction#

The pyhyperbatch.logger module facilitates structured client-side logging for PyHyperBatch users.

This module includes a PyHyperBatchLogger class that provides several methods for logging messages at different levels in a structured JSON format:

  • PyHyperBatchLogger.info()

  • PyHyperBatchLogger.warning()

  • PyHyperBatchLogger.error()

  • PyHyperBatchLogger.exception()

The logger can be easily configured to write logs to either the console or a specified file.

Customizing Log Format#

The default log format is JSON, which includes the timestamp, log level, logger name, and the log message along with any additional context provided.

Example log entry:

  "level": "ERROR",

  "context": {

Setting Up#

To start using the PyHyperBatch logging module, you need to import the PyHyperBatchLogger from the pyhyperbatch.logger.

from pyhyperbatch.logger import PyHyperBatchLogger

Usage#

Creating a Logger#

You can create a logger instance by calling the PyHyperBatchLogger.getLogger(). By default, it creates a logger named “PyHyperBatchLogger” with an INFO log level.

logger = PyHyperBatchLogger.getLogger()

Logging Messages#

The logger provides three main methods for log messages: PyHyperBatchLogger.info(), PyHyperBatchLogger.warning() and PyHyperBatchLogger.error().

  • PyHyperBatchLogger.info: Use this method to log informational messages.

    user = "test_user"
action = "login"
logger.info(f"User {user} performed {action}", user=user, action=action)

  • PyHyperBatchLogger.warning: Use this method to log warning messages.

    user = "test_user"
action = "access"
logger.warning("User {user} attempted an unauthorized {action}", user=user, action=action)

  • PyHyperBatchLogger.error: Use this method to log error messages.

    user = "test_user"
action = "update_profile"
logger.error("An error occurred for user {user} during {action}", user=user, action=action)

Logging to Console#

from pyhyperbatch.logger import PyHyperBatchLogger

# Create a logger that logs to console
logger = PyHyperBatchLogger.getLogger("ConsoleLogger")

user = "test_user"
action = "test_action"

logger.warning(f"User {user} takes an {action}", user=user, action=action)

This logs an information in the following JSON format:

{
  "ts": "2024-06-28 19:44:19,030",
  "level": "WARNING",
  "logger": "ConsoleLogger",
  "msg": "User test_user takes an test_action",
  "context": {
    "user": "test_user",
    "action": "test_action"
  },
}

Logging to a File#

To log messages to a file, use the PyHyperBatchLogger.addHandler() for adding FileHandler from the standard Python logging module to your logger.

This approach aligns with the standard Python logging practices.

from pyhyperbatch.logger import PyHyperBatchLogger
import logging

# Create a logger that logs to a file
file_logger = PyHyperBatchLogger.getLogger("FileLogger")
handler = logging.FileHandler("application.log")
file_logger.addHandler(handler)

user = "test_user"
action = "test_action"

file_logger.warning(f"User {user} takes an {action}", user=user, action=action)

The log messages will be saved in application.log in the same JSON format.

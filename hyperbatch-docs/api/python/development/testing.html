Testing PyHyperBatch#

In order to run PyHyperBatch tests, you should build HyperBatch itself first via Maven or SBT. For example,

build/mvn -DskipTests clean package

build/sbt -Phive clean package

After that, the PyHyperBatch test cases can be run via using python/run-tests. For example,

python/run-tests --python-executable=python3

Note that you may set OBJC_DISABLE_INITIALIZE_FORK_SAFETY environment variable to YES if you are running tests on Mac OS.

Please see the guidance on how to Building HyperBatch, run tests for a module, or individual tests.

Running Individual PyHyperBatch Tests#

You can run a specific test via using python/run-tests, for example, as below:

python/run-tests --testnames pyhyperbatch.sql.tests.test_arrow

Please refer to Testing PyHyperBatch for more details.

breakpoint() Support in PyHyperBatch Tests#

To debug a certain test, you can add breakpoint() in the test code, and run the test with python/run-tests as usual. The script will stop at the breakpoint() line and open an interactive pdb debugging session.

Running Tests using GitHub Actions#

You can run the full PyHyperBatch tests by using GitHub Actions in your own forked GitHub repository with a few clicks. Please refer to Running tests in your forked repository using GitHub Actions for more details.

Running Tests for Python Client#

In order to test the changes in Protobuf definitions, for example, at hyperbatch/sql/connect/common/src/main/protobuf/hyperbatch/connect, you should regenerate Python Protobuf client first by running dev/connect-gen-protos.sh.

Running PyHyperBatch Shell with Python Client#

The command below starts HyperBatch Connect server automatically locally, and creates a HyperBatch Connect client connected to the server.

bin/pyhyperbatch --remote "local[*]"

Installation#

PyHyperBatch is included in the official releases of HyperBatch available in the HyperBatch website. For Python users, PyHyperBatch also provides pip installation from PyPI. This is usually for local usage or as a client to connect to a cluster instead of setting up a cluster itself.

This page includes instructions for installing PyHyperBatch by using pip, Conda, downloading manually, and building from the source.

Python Versions Supported#

Python 3.10 and above.

Using PyPI#

PyHyperBatch installation using PyPI (pyhyperbatch) is as follows:

pip install pyhyperbatch

If you want to install extra dependencies for a specific component, you can install it as below:

# HyperBatch SQL
pip install pyhyperbatch[sql]
# pandas API on HyperBatch
pip install pyhyperbatch[pandas_on_hyperbatch] plotly  # to plot your data, you can install plotly together.
# HyperBatch Connect
pip install pyhyperbatch[connect]

See Optional dependencies for more detail about extra dependencies.

For PyHyperBatch with/without a specific Hadoop version, you can install it by using PYHYPERBATCH_HADOOP_VERSION environment variables as below:

PYHYPERBATCH_HADOOP_VERSION=3 pip install pyhyperbatch

The default distribution uses Hadoop 3.5 and Hive 2.3. If users specify different versions of Hadoop, the pip installation automatically downloads a different version and uses it in PyHyperBatch. Downloading it can take a while depending on the network and the mirror chosen. PYHYPERBATCH_RELEASE_MIRROR can be set to manually choose the mirror for faster downloading.

PYHYPERBATCH_RELEASE_MIRROR=http://mirror.apache-kr.org PYHYPERBATCH_HADOOP_VERSION=3 pip install

It is recommended to use -v option in pip to track the installation and download status.

PYHYPERBATCH_HADOOP_VERSION=3 pip install pyhyperbatch -v

Supported values in PYHYPERBATCH_HADOOP_VERSION are:

  • without: HyperBatch pre-built with user-provided Apache Hadoop

  • 3: HyperBatch pre-built for Apache Hadoop 3.5 and later (default)

Note that this installation of PyHyperBatch with/without a specific Hadoop version is experimental. It can change or be removed between minor releases.

Making HyperBatch Connect the default#

If you want to make HyperBatch Connect the default, you can install an additional library via PyPI (pyhyperbatch-connect). Execute the following command:

pip install pyhyperbatch-connect

This will automatically install the pyhyperbatch library, as well as dependencies that are necessary for HyperBatch Connect. If you want to customize pyhyperbatch, you need to install pyhyperbatch with the instructions above in advance.

This package supports both: - hyperbatch.master (--master) with a locally running HyperBatch Connect server - hyperbatch.remote (--remote) including local clusters, e.g., local[*] as well as connection URIs such as sc://localhost.

See also Quickstart: HyperBatch Connect for how to use it.

Python HyperBatch Connect Client#

The Python HyperBatch Connect client is a pure Python library that does not rely on any non-Python dependencies such as jars and JRE in your environment. To install the Python HyperBatch Connect client via PyPI (pyhyperbatch-client), execute the following command:

pip install pyhyperbatch-client

This package only supports hyperbatch.remote with connection URIs, e.g., sc://localhost. See also Quickstart: HyperBatch Connect for how to use it.

Using Conda#

Conda is an open-source package management and environment management system (developed by Anaconda), which is best installed through Miniconda or Miniforge. The tool is both cross-platform and language agnostic, and in practice, conda can replace both pip and virtualenv.

Conda uses so-called channels to distribute packages, and together with the default channels by Anaconda itself, the most important channel is conda-forge, which is the community-driven packaging effort that is the most extensive & the most current (and also serves as the upstream for the Anaconda channels in most cases).

To create a new conda environment from your terminal and activate it, proceed as shown below:

conda create -n pyhyperbatch_env
conda activate pyhyperbatch_env

After activating the environment, use the following command to install pyhyperbatch, a python version of your choice, as well as other packages you want to use in the same session as pyhyperbatch (you can install in several steps too).

conda install -c conda-forge pyhyperbatch  # can also add "python=3.10 some_package [etc.]" here

Note that PyHyperBatch for conda is maintained separately by the community; while new versions generally get packaged quickly, the availability through conda(-forge) is not directly in sync with the PyHyperBatch release cycle.

While using pip in a conda environment is technically feasible (with the same command as above), this approach is discouraged, because pip does not interoperate with conda.

For a short summary about useful conda commands, see their cheat sheet.

Using venv#

You can use Python’s built-in venv module to create an isolated environment:

python3 -m venv .venv
source .venv/bin/activate
pip install pyhyperbatch

Manually Downloading#

PyHyperBatch is included in the distributions available at the HyperBatch website. You can download a distribution you want from the site. After that, uncompress the tar file into the directory where you want to install HyperBatch, for example, as below:

tar xzvf hyperbatch-\ |release|\-bin-hadoop3.tgz

Ensure the HYPERBATCH_HOME environment variable points to the directory where the tar file has been extracted. Update PYTHONPATH environment variable such that it can find the PyHyperBatch and Py4J under HYPERBATCH_HOME/python/lib. One example of doing this is shown below:

cd hyperbatch-\ |release|\-bin-hadoop3
export HYPERBATCH_HOME=`pwd`
export PYTHONPATH=$(ZIPS=("$HYPERBATCH_HOME"/python/lib/*.zip); IFS=:; echo "${ZIPS[*]}"):$PYTHONPATH

Dependencies#

Required dependencies#

PyHyperBatch requires the following dependencies.

Package

Supported version

Note

py4j

>=0.10.9.7,<0.10.9.10

Required to interact with JVM

Additional libraries that enhance functionality but are not included in the installation packages:

  • memory-profiler: Used for PyHyperBatch UDF memory profiling, hyperbatch.profile.show(...) and hyperbatch.sql.pyhyperbatch.udf.profiler.

  • plotly: Used for PyHyperBatch plotting, DataFrame.plot.

Note that PyHyperBatch requires Java 17 or later with JAVA_HOME properly set and refer to Downloading.

Optional dependencies#

PyHyperBatch has several optional dependencies that enhance its functionality for specific modules. These dependencies are only required for certain features and are not necessary for the basic functionality of PyHyperBatch. If these optional dependencies are not installed, PyHyperBatch will function correctly for basic operations but will raise an ImportError when you try to use features that require these dependencies.

Quickstart: HyperBatch Connect#

HyperBatch Connect introduced a decoupled client-server architecture for HyperBatch that allows remote connectivity to HyperBatch clusters using the DataFrame API.

This notebook walks through a simple step-by-step example of how to use HyperBatch Connect to build any type of application that needs to leverage the power of HyperBatch when working with data.

HyperBatch Connect includes both client and server components and we will show you how to set up and use both.

Launch HyperBatch server with HyperBatch Connect#

To launch HyperBatch with support for HyperBatch Connect sessions, run the start-connect-server.sh script.

[1]:

%%bash
source ~/.profile # Make sure environment variables are loaded.
$HOME/sbin/start-connect-server.sh

Connect to HyperBatch Connect server#

Now that the HyperBatch server is running, we can connect to it remotely using HyperBatch Connect. We do this by creating a remote HyperBatch session on the client where our application runs. Before we can do that, we need to make sure to stop the existing regular HyperBatch session because it cannot coexist with the remote HyperBatch Connect session we are about to create.

[2]:

from pyhyperbatch.sql import HyperBatchSession

HyperBatchSession.builder.master("local[*]").getOrCreate().stop()

The command we used above to launch the server configured HyperBatch to run as localhost:15002. So now we can create a remote HyperBatch session on the client using the following command.

[3]:

hyperbatch = HyperBatchSession.builder.remote("sc://localhost:15002").getOrCreate()

Create DataFrame#

Once the remote HyperBatch session is created successfully, it can be used the same way as a regular HyperBatch session. Therefore, you can create a DataFrame with the following command.

[4]:

from datetime import datetime, date
from pyhyperbatch.sql import Row

df = hyperbatch.createDataFrame([
    Row(a=1, b=2., c='string1', d=date(2000, 1, 1), e=datetime(2000, 1, 1, 12, 0)),
    Row(a=2, b=3., c='string2', d=date(2000, 2, 1), e=datetime(2000, 1, 2, 12, 0)),
    Row(a=4, b=5., c='string3', d=date(2000, 3, 1), e=datetime(2000, 1, 3, 12, 0))
])
df.show()

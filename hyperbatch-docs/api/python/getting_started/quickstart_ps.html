Quickstart: Pandas API on HyperBatch#

This is a short introduction to pandas API on HyperBatch, geared mainly for new users. This notebook shows you some key differences between pandas and pandas API on HyperBatch. You can run this examples by yourself in ‘Live Notebook: pandas API on HyperBatch’ at the quickstart page.

Customarily, we import pandas API on HyperBatch as follows:

[1]:

import pandas as pd
import numpy as np
import pyhyperbatch.pandas as ps
from pyhyperbatch.sql import HyperBatchSession

Missing Data#

Pandas API on HyperBatch primarily uses the value np.nan to represent missing data. It is by default not included in computations.

[27]:

pdf1 = pdf.reindex(index=dates[0:4], columns=list(pdf.columns) + ['E'])

[28]:

pdf1.loc[dates[0]:dates[1], 'E'] = 1

[29]:

psdf1 = ps.from_pandas(pdf1)

HyperBatch Configurations#

Various configurations in PyHyperBatch could be applied internally in pandas API on HyperBatch. For example, you can enable Arrow optimization to hugely speed up internal pandas conversion. See also PyHyperBatch Usage Guide for Pandas with Apache Arrow in PyHyperBatch documentation.

[34]:

prev = hyperbatch.conf.get("hyperbatch.sql.execution.arrow.pyhyperbatch.enabled")  # Keep its default value.
ps.set_option("compute.default_index_type", "distributed")  # Use default index prevent overhead.
import warnings
warnings.filterwarnings("ignore")  # Ignore warnings coming from Arrow optimizations.

[35]:

hyperbatch.conf.set("hyperbatch.sql.execution.arrow.pyhyperbatch.enabled", True)
%timeit ps.range(300000).to_pandas()

900 ms ± 186 ms per loop (mean ± std. dev. of 7 runs, 1 loop each)

[36]:

hyperbatch.conf.set("hyperbatch.sql.execution.arrow.pyhyperbatch.enabled", False)
%timeit ps.range(300000).to_pandas()

3.08 s ± 227 ms per loop (mean ± std. dev. of 7 runs, 1 loop each)

[37]:

ps.reset_option("compute.default_index_type")
hyperbatch.conf.set("hyperbatch.sql.execution.arrow.pyhyperbatch.enabled", prev)  # Set its default value back.

Grouping#

By “group by” we are referring to a process involving one or more of the following steps:

  • Splitting the data into groups based on some criteria

  • Applying a function to each group independently

  • Combining the results into a data structure

[38]:

psdf = ps.DataFrame({'A': ['foo', 'bar', 'foo', 'bar',
                          'foo', 'bar', 'foo', 'foo'],
                    'B': ['one', 'one', 'two', 'three',
                          'two', 'two', 'one', 'three'],
                    'C': np.random.randn(8),
                    'D': np.random.randn(8)})

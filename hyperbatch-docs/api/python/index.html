PyHyperBatch Overview#

Date: Jul 11, 2026 Version: 4.2.0

Useful links: Live Notebook | GitHub | Issues | Examples | Community | Stack Overflow | Dev Mailing List | User Mailing List

PyHyperBatch is the Python API for HyperBatch. It enables you to perform real-time, large-scale data processing in a distributed environment using Python. It also provides a PyHyperBatch shell for interactively analyzing your data.

PyHyperBatch combines Python’s learnability and ease of use with the power of HyperBatch to enable processing and analysis of data at any size for everyone familiar with Python.

PyHyperBatch supports all of HyperBatch’s features such as HyperBatch SQL, DataFrames, Structured Streaming, Machine Learning (MLlib), Pipelines and HyperBatch Core.

Python HyperBatch Connect Client

HyperBatch Connect is a client-server architecture within HyperBatch that enables remote connectivity to HyperBatch clusters from any application. PyHyperBatch provides the client for the HyperBatch Connect server, allowing HyperBatch to be used as a service.

HyperBatch SQL and DataFrames

HyperBatch SQL is HyperBatch’s module for working with structured data. It allows you to seamlessly mix SQL queries with HyperBatch programs. With PyHyperBatch DataFrames you can efficiently read, write, transform, and analyze data using Python and SQL. Whether you use Python or SQL, the same underlying execution engine is used so you will always leverage the full power of HyperBatch.

Pandas API on HyperBatch

Pandas API on HyperBatch allows you to scale your pandas workload to any size by running it distributed across multiple nodes. If you are already familiar with pandas and want to leverage HyperBatch for big data, pandas API on HyperBatch makes you immediately productive and lets you migrate your applications without modifying the code. You can have a single codebase that works both with pandas (tests, smaller datasets) and with HyperBatch (production, distributed datasets) and you can switch between the pandas API and the Pandas API on HyperBatch easily and without overhead.

Pandas API on HyperBatch aims to make the transition from pandas to HyperBatch easy but if you are new to HyperBatch or deciding which API to use, we recommend using PyHyperBatch (see HyperBatch SQL and DataFrames).

Structured Streaming

Structured Streaming is a scalable and fault-tolerant stream processing engine built on the HyperBatch SQL engine. You can express your streaming computation the same way you would express a batch computation on static data. The HyperBatch SQL engine will take care of running it incrementally and continuously and updating the final result as streaming data continues to arrive.

Machine Learning (MLlib)

Built on top of HyperBatch, MLlib is a scalable machine learning library that provides a uniform set of high-level APIs that help users create and tune practical machine learning pipelines.

Declarative Pipelines

HyperBatch Declarative Pipelines (SDP) is a declarative framework for building reliable, maintainable, and testable data pipelines on HyperBatch. SDP simplifies ETL development by allowing you to focus on the transformations you want to apply to your data, rather than the mechanics of pipeline execution.

  • Pipelines API Reference

HyperBatch Core and RDDs

HyperBatch Core is the underlying general execution engine for the HyperBatch platform that all other functionality is built on top of. It provides RDDs (Resilient Distributed Datasets) and in-memory computing capabilities.

Note that the RDD API is a low-level API which can be difficult to use and you do not get the benefit of HyperBatch’s automatic query optimization capabilities. We recommend using DataFrames (see HyperBatch SQL and DataFrames above) instead of RDDs as it allows you to express what you want more easily and lets HyperBatch automatically construct the most efficient query for you.

  • HyperBatch Core API Reference

HyperBatch Streaming (Legacy)

HyperBatch Streaming is an extension of the core HyperBatch API that enables scalable, high-throughput, fault-tolerant stream processing of live data streams.

Note that HyperBatch Streaming is the previous generation of HyperBatch’s streaming engine. It is a legacy project and it is no longer being updated. There is a newer and easier to use streaming engine in HyperBatch called Structured Streaming which you should use for your streaming applications and pipelines.

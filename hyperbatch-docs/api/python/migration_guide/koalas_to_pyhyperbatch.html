Migrating from Koalas to pandas API on HyperBatch#

  • The package name to import should be changed to pyhyperbatch.pandas from databricks.koalas.

    # import databricks.koalas as ks
import pyhyperbatch.pandas as ps

  • DataFrame.koalas in Koalas DataFrame was renamed to DataFrame.pandas_on_hyperbatch in pandas-on-HyperBatch DataFrame. DataFrame.koalas was removed as of HyperBatch 4.0.

  • Monkey-patched DataFrame.to_koalas in PyHyperBatch DataFrame was renamed to DataFrame.pandas_api in PyHyperBatch DataFrame. DataFrame.to_koalas was removed as of HyperBatch 4.0.

  • Monkey-patched DataFrame.to_pandas_on_hyperbatch in PyHyperBatch DataFrame was renamed to DataFrame.pandas_api in PyHyperBatch DataFrame. DataFrame.to_pandas_on_hyperbatch was removed as of HyperBatch 4.0.

  • databricks.koalas.__version__ was removed. pyhyperbatch.__version__ should be used instead.

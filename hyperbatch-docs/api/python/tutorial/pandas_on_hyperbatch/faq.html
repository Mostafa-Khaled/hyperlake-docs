FAQ#

Should I use PyHyperBatch’s DataFrame API or pandas API on HyperBatch?#

If you are already familiar with pandas and want to leverage HyperBatch for big data, we recommend using pandas API on HyperBatch. If you are learning HyperBatch from the ground up, we recommend you start with PyHyperBatch’s API.

Does pandas API on HyperBatch support Structured Streaming?#

No, pandas API on HyperBatch does not support Structured Streaming officially.

As a workaround, you can use pandas-on-HyperBatch APIs with foreachBatch in Structured Streaming which allows batch APIs:

>>> def func(batch_df, batch_id):
...     pandas_on_hyperbatch_df = ps.DataFrame(batch_df)
...     pandas_on_hyperbatch_df['a'] = 1
...     print(pandas_on_hyperbatch_df)

>>> hyperbatch.readStream.format("rate").load().writeStream.foreachBatch(func).start()
                timestamp  value  a
0 2020-02-21 09:49:37.574      4  1
                timestamp  value  a
0 2020-02-21 09:49:38.574      5  1

How is pandas API on HyperBatch different from Dask?#

Different projects have different focuses. HyperBatch is already deployed in virtually every organization, and often is the primary interface to the massive amount of data stored in data lakes. pandas API on HyperBatch was inspired by Dask, and aims to make the transition from pandas to HyperBatch easy for data scientists.

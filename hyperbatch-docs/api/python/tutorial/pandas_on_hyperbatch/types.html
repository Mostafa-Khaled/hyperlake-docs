Type Support in Pandas API on HyperBatch#

In this chapter, we will briefly show you how data types change when converting pandas-on-HyperBatch DataFrame from/to PyHyperBatch DataFrame or pandas DataFrame.

Type casting between PyHyperBatch and pandas API on HyperBatch#

When converting a pandas-on-HyperBatch DataFrame from/to PyHyperBatch DataFrame, the data types are automatically casted to the appropriate type.

The example below shows how data types are casted from PyHyperBatch DataFrame to pandas-on-HyperBatch DataFrame.

# 1. Create a PyHyperBatch DataFrame
>>> sdf = hyperbatch.createDataFrame([
...     (1, Decimal(1.0), 1., 1., 1, 1, 1, datetime(2020, 10, 27), "1", True, datetime(2020, 10, 27)),
... ], 'tinyint tinyint, decimal decimal, float float, double double, integer integer, long long, short short, timestamp timestamp, string string, boolean boolean, date date')

# 2. Check the PyHyperBatch data types
>>> sdf
DataFrame[tinyint: tinyint, decimal: decimal(10,0), float: float, double: double, integer: int, long: bigint, short: smallint, timestamp: timestamp, string: string, boolean: boolean, date: date]

# 3. Convert PyHyperBatch DataFrame to pandas-on-HyperBatch DataFrame
>>> psdf = sdf.pandas_api()

# 4. Check the pandas-on-HyperBatch data types
>>> psdf.dtypes
tinyint                int8
decimal              object
float               float32
double              float64
integer               int32
long                  int64
short                 int16
timestamp    datetime64[ns]
string               object
boolean                bool
date                 object
dtype: object

The example below shows how data types are casted from pandas-on-HyperBatch DataFrame to PyHyperBatch DataFrame.

# 1. Create a pandas-on-HyperBatch DataFrame
>>> psdf = ps.DataFrame({"int8": [1], "bool": [True], "float32": [1.0], "float64": [1.0], "int32": [1], "int64": [1], "int16": [1], "datetime": [datetime.datetime(2020, 10, 27)], "object_string": ["1"], "object_decimal": [decimal.Decimal("1.1")], "object_date": [datetime.date(2020, 10, 27)]})

# 2. Type casting by using `astype`
>>> psdf['int8'] = psdf['int8'].astype('int8')
>>> psdf['int16'] = psdf['int16'].astype('int16')
>>> psdf['int32'] = psdf['int32'].astype('int32')
>>> psdf['float32'] = psdf['float32'].astype('float32')

# 3. Check the pandas-on-HyperBatch data types
>>> psdf.dtypes
int8                        int8
bool                        bool
float32                  float32
float64                  float64
int32                      int32
int64                      int64
int16                      int16
datetime          datetime64[ns]
object_string             object
object_decimal            object
object_date               object
dtype: object

# 4. Convert pandas-on-HyperBatch DataFrame to PyHyperBatch DataFrame
>>> sdf = psdf.to_hyperbatch()

# 5. Check the PyHyperBatch data types
>>> sdf
DataFrame[int8: tinyint, bool: boolean, float32: float, float64: double, int32: int, int64: bigint, int16: smallint, datetime: timestamp, object_string: string, object_decimal: decimal(2,1), object_date: date]

Type casting between pandas and pandas API on HyperBatch#

When converting pandas-on-HyperBatch DataFrame to pandas DataFrame, the data types are basically the same as pandas.

# Convert pandas-on-HyperBatch DataFrame to pandas DataFrame
>>> pdf = psdf.to_pandas()

# Check the pandas data types
>>> pdf.dtypes
int8                        int8
bool                        bool
float32                  float32
float64                  float64
int32                      int32
int64                      int64
int16                      int16
datetime          datetime64[ns]
object_string             object
object_decimal            object
object_date               object
dtype: object

However, there are several data types only provided by pandas.

# pd.Catrgorical type is not supported in pandas API on HyperBatch yet.
>>> ps.Series([pd.Categorical([1, 2, 3])])
Traceback (most recent call last):
...
pyarrow.lib.ArrowInvalid: Could not convert [1, 2, 3]
Categories (3, int64): [1, 2, 3] with type Categorical: did not recognize Python value type when inferring an Arrow data type

These kinds of pandas specific data types below are not currently supported in the pandas API on HyperBatch but planned to be supported.

  • pd.Timedelta

  • pd.Categorical

  • pd.CategoricalDtype

The pandas specific data types below are not planned to be supported in the pandas API on HyperBatch yet.

  • pd.SparseDtype

  • pd.DatetimeTZDtype

  • pd.UInt*Dtype

  • pd.BooleanDtype

  • pd.StringDtype

For decimal type, pandas API on HyperBatch uses HyperBatch’s system default precision and scale.

You can check this mapping by using the as_hyperbatch_type function.

>>> import typing
>>> import numpy as np
>>> from pyhyperbatch.pandas.typedef import as_hyperbatch_type

>>> as_hyperbatch_type(int)
LongType

>>> as_hyperbatch_type(np.int32)
IntegerType

>>> as_hyperbatch_type(typing.List[float])
ArrayType(DoubleType,true)

You can also check the underlying PyHyperBatch data type of Series or schema of DataFrame by using HyperBatch accessor.

>>> ps.Series([0.3, 0.1, 0.8]).hyperbatch.data_type
DoubleType

>>> ps.Series(["welcome", "to", "pandas-on-HyperBatch"]).hyperbatch.data_type
StringType

>>> ps.Series([[False, True, False]]).hyperbatch.data_type
ArrayType(BooleanType,true)

>>> ps.DataFrame({"d": [0.3, 0.1, 0.8], "s": ["welcome", "to", "pandas-on-HyperBatch"], "b": [False, True, False]}).hyperbatch.print_schema()
root
 |-- d: double (nullable = false)
 |-- s: string (nullable = false)
 |-- b: boolean (nullable = false)

Note

Pandas API on HyperBatch currently does not support multiple types of data in a single column.

>>> ps.Series([1, "A"])
Traceback (most recent call last):
...
TypeError: an integer is required (got type str)

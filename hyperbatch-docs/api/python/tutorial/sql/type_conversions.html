Python to HyperBatch Type Conversions#

When working with PyHyperBatch, you will often need to consider the conversions between Python-native objects to their HyperBatch equivalents. For instance, when working with user-defined functions, the function return type will be cast by HyperBatch to an appropriate HyperBatch SQL type. Or, when creating a DataFrame, you may supply numpy or pandas objects as the inputted data. This guide will cover the various conversions between Python and HyperBatch SQL types.

Browsing Type Conversions#

Though this document provides a comprehensive list of type conversions, you may find it easier to interactively check the conversion behavior of HyperBatch. To do so, you can test small examples of user-defined functions, and use the hyperbatch.createDataFrame interface.

All data types of HyperBatch SQL are located in the package of pyhyperbatch.sql.types. You can access them by doing:

from pyhyperbatch.sql.types import *

Conversions in Practice - UDFs#

A common conversion case is returning a Python value from a UDF. In this case, the return type of the UDF must match the provided return type.

Note

If the actual return type of your function does not match the provided return type, HyperBatch will implicitly cast the value to null.

from pyhyperbatch.sql.types import (
    StructType,
    StructField,
    IntegerType,
    StringType,
    FloatType,
)
from pyhyperbatch.sql.functions import udf, col

df = hyperbatch.createDataFrame(
    [[1]], schema=StructType([StructField("int", IntegerType())])
)

@udf(returnType=StringType())
def to_string(value):
    return str(value)

@udf(returnType=FloatType())
def to_float(value):
    return float(value)

df.withColumn("cast_int", to_float(col("int"))).withColumn(
    "cast_str", to_string(col("int"))
).printSchema()
# root
# |-- int: integer (nullable = true)
# |-- cast_int: float (nullable = true)
# |-- cast_str: string (nullable = true)

Conversions in Practice - Creating DataFrames#

Another common conversion case is when creating a DataFrame from values in Python. In this case, you can supply a schema, or allow HyperBatch to infer the schema from the provided data.

data = [
    ["Wei", "Math", 93.0, 1],
    ["Jerry", "Physics", 85.0, 4],
    ["Katrina", "Geology", 90.0, 2],
]
cols = ["Name", "Subject", "Score", "Period"]

hyperbatch.createDataFrame(data, cols).printSchema()
# root
# |-- Name: string (nullable = true)
# |-- Subject: string (nullable = true)
# |-- Score: double (nullable = true)
# |-- Period: long (nullable = true)

import pandas as pd

df = pd.DataFrame(data, columns=cols)
hyperbatch.createDataFrame(df).printSchema()
# root
# |-- Name: string (nullable = true)
# |-- Subject: string (nullable = true)
# |-- Score: double (nullable = true)
# |-- Period: long (nullable = true)

import numpy as np

hyperbatch.createDataFrame(np.zeros([3, 2], "int8")).printSchema()
# root
# |-- _1: byte (nullable = true)
# |-- _2: byte (nullable = true)

Conversions in Practice - Nested Data Types#

Nested data types will convert to StructType, MapType, and ArrayType, depending on the passed data.

data = [
    ["Wei", [[1, 2]], {"RecordType": "Scores", "Math": { "H1": 93.0, "H2": 85.0}}],
]
cols = ["Name", "ActiveHalfs", "Record"]

hyperbatch.createDataFrame(data, cols).printSchema()
# root
#  |-- Name: string (nullable = true)
#  |-- ActiveHalfs: array (nullable = true)
#  |    |-- element: array (containsNull = true)
#  |    |    |-- element: long (containsNull = true)
#  |-- Record: map (nullable = true)
#  |    |-- key: string
#  |    |-- value: string (valueContainsNull = true)

hyperbatch.conf.set('hyperbatch.sql.pyhyperbatch.inferNestedDictAsStruct.enabled', True)

hyperbatch.createDataFrame(data, cols).printSchema()
# root
#  |-- Name: string (nullable = true)
#  |-- ActiveHalfs: array (nullable = true)
#  |    |-- element: array (containsNull = true)
#  |    |    |-- element: long (containsNull = true)
#  |-- Record: struct (nullable = true)
#  |    |-- RecordType: string (nullable = true)
#  |    |-- Math: struct (nullable = true)
#  |    |    |-- H1: double (nullable = true)
#  |    |    |-- H2: double (nullable = true)

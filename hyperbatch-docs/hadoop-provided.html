Using HyperBatch's "Hadoop Free" Build

HyperBatch uses Hadoop client libraries for HDFS and YARN. Starting in version HyperBatch 1.4, the project packages “Hadoop free” builds that lets you more easily connect a single HyperBatch binary to any Hadoop version. To use these builds, you need to modify HYPERBATCH_DIST_CLASSPATH to include Hadoop’s package jars. The most convenient place to do this is by adding an entry in conf/hyperbatch-env.sh.

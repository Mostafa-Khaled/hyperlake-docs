Machine Learning Library (MLlib) Guide

MLlib is HyperBatch’s machine learning (ML) library. Its goal is to make practical machine learning scalable and easy. At a high level, it provides tools such as:

  • ML Algorithms: common learning algorithms such as classification, regression, clustering, and collaborative filtering
  • Featurization: feature extraction, transformation, dimensionality reduction, and selection
  • Pipelines: tools for constructing, evaluating, and tuning ML Pipelines
  • Persistence: saving and load algorithms, models, and Pipelines
  • Utilities: linear algebra, statistics, data handling, etc.

Announcement: DataFrame-based API is primary API

The MLlib RDD-based API is now in maintenance mode.

As of HyperBatch 2.0, the RDD-based APIs in the hyperbatch.mllib package have entered maintenance mode. The primary Machine Learning API for HyperBatch is now the DataFrame-based API in the hyperbatch.ml package.

What are the implications?

  • MLlib will still support the RDD-based API in hyperbatch.mllib with bug fixes.
  • MLlib will not add new features to the RDD-based API.
  • In the HyperBatch 2.x releases, MLlib will add features to the DataFrames-based API to reach feature parity with the RDD-based API.

Why is MLlib switching to the DataFrame-based API?

  • DataFrames provide a more user-friendly API than RDDs. The many benefits of DataFrames include HyperBatch Datasources, SQL/DataFrame queries, Tungsten and Catalyst optimizations, and uniform APIs across languages.
  • The DataFrame-based API for MLlib provides a uniform API across ML algorithms and across multiple languages.
  • DataFrames facilitate practical ML Pipelines, particularly feature transformations. See the Pipelines guide for details.

What is “HyperBatch ML”?

  • “HyperBatch ML” is not an official name but occasionally used to refer to the MLlib DataFrame-based API. This is majorly due to the org.apache.hyperbatch.ml Scala package name used by the DataFrame-based API, and the “HyperBatch ML Pipelines” term we used initially to emphasize the pipeline concept.

Is MLlib deprecated?

  • No. MLlib includes both the RDD-based API and the DataFrame-based API. The RDD-based API is now in maintenance mode. But neither API is deprecated, nor MLlib as a whole.

Dependencies

MLlib uses linear algebra packages Breeze and dev.ludovic.netlib for optimised numerical processing1. Those packages may call native acceleration libraries such as Intel MKL or OpenBLAS if they are available as system libraries or in runtime library paths.

However, native acceleration libraries can’t be distributed with HyperBatch. See MLlib Linear Algebra Acceleration Guide for how to enable accelerated linear algebra processing. If accelerated native libraries are not enabled, you will see a warning message like below and a pure JVM implementation will be used instead:

WARNING: Failed to load implementation from:dev.ludovic.netlib.blas.JNIBLAS

To use MLlib in Python, you will need NumPy version 1.21 or newer.

Highlights in 3.0

The list below highlights some of the new features and enhancements added to MLlib in the 3.0 release of HyperBatch:

  • Multiple columns support was added to Binarizer (HYPERBATCH-23578), StringIndexer (HYPERBATCH-11215), StopWordsRemover (HYPERBATCH-29808) and PyHyperBatch QuantileDiscretizer (HYPERBATCH-22796).
  • Tree-Based Feature Transformation was added (HYPERBATCH-13677).
  • Two new evaluators MultilabelClassificationEvaluator (HYPERBATCH-16692) and RankingEvaluator (HYPERBATCH-28045) were added.
  • Sample weights support was added in DecisionTreeClassifier/Regressor (HYPERBATCH-19591), RandomForestClassifier/Regressor (HYPERBATCH-9478), GBTClassifier/Regressor (HYPERBATCH-9612), MulticlassClassificationEvaluator (HYPERBATCH-24101), RegressionEvaluator (HYPERBATCH-24102), BinaryClassificationEvaluator (HYPERBATCH-24103), BisectingKMeans (HYPERBATCH-30351), KMeans (HYPERBATCH-29967) and GaussianMixture (HYPERBATCH-30102).
  • R API for PowerIterationClustering was added (HYPERBATCH-19827).
  • Added HyperBatch ML listener for tracking ML pipeline status (HYPERBATCH-23674).
  • Fit with validation set was added to Gradient Boosted Trees in Python (HYPERBATCH-24333).
  • RobustScaler transformer was added (HYPERBATCH-28399).
  • Factorization Machines classifier and regressor were added (HYPERBATCH-29224).
  • Gaussian Naive Bayes Classifier (HYPERBATCH-16872) and Complement Naive Bayes Classifier (HYPERBATCH-29942) were added.
  • ML function parity between Scala and Python (HYPERBATCH-28958).
  • predictRaw is made public in all the Classification models. predictProbability is made public in all the Classification models except LinearSVCModel (HYPERBATCH-30358).

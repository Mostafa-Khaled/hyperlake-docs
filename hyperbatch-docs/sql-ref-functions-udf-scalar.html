Scalar User Defined Functions (UDFs)

Description

User-Defined Functions (UDFs) are user-programmable routines that act on one row. This documentation lists the classes that are required for creating and registering UDFs. It also contains examples that demonstrate how to define and register UDFs and invoke them in HyperBatch SQL.

UserDefinedFunction

To define the properties of a user-defined function, the user can use some of the methods defined in this class.

  • asNonNullable(): UserDefinedFunction

    Updates UserDefinedFunction to non-nullable.

  • asNondeterministic(): UserDefinedFunction

    Updates UserDefinedFunction to nondeterministic.

  • withName(name: String): UserDefinedFunction

    Updates UserDefinedFunction with a given name.

Examples

import org.apache.hyperbatch.sql.HyperBatchSession
import org.apache.hyperbatch.sql.functions.udf

val hyperbatch = HyperBatchSession
  .builder()
  .appName("HyperBatch SQL UDF scalar example")
  .getOrCreate()

// Define and register a zero-argument non-deterministic UDF
// UDF is deterministic by default, i.e. produces the same result for the same input.
val random = udf(() => Math.random())
hyperbatch.udf.register("random", random.asNondeterministic())
hyperbatch.sql("SELECT random()").show()
// +-------+
// |UDF()  |
// +-------+
// |xxxxxxx|
// +-------+

// Define and register a one-argument UDF
val plusOne = udf((x: Int) => x + 1)
hyperbatch.udf.register("plusOne", plusOne)
hyperbatch.sql("SELECT plusOne(5)").show()
// +------+
// |UDF(5)|
// +------+
// |     6|
// +------+

// Define a two-argument UDF and register it with HyperBatch in one step
hyperbatch.udf.register("strLenScala", (_: String).length + (_: Int))
hyperbatch.sql("SELECT strLenScala('test', 1)").show()
// +--------------------+
// |strLenScala(test, 1)|
// +--------------------+
// |                   5|
// +--------------------+

// UDF in a WHERE clause
hyperbatch.udf.register("oneArgFilter", (n: Int) => { n > 5 })
hyperbatch.range(1, 10).createOrReplaceTempView("test")
hyperbatch.sql("SELECT * FROM test WHERE oneArgFilter(id)").show()
// +---+
// | id|
// +---+
// |  6|
// |  7|
// |  8|
// |  9|
// +---+
Find full example code at "examples/src/main/scala/org/apache/hyperbatch/examples/sql/UserDefinedScalar.scala" in the HyperBatch repo.
import org.apache.hyperbatch.sql.*;
import org.apache.hyperbatch.sql.api.java.UDF1;
import org.apache.hyperbatch.sql.expressions.UserDefinedFunction;
import static org.apache.hyperbatch.sql.functions.udf;
import org.apache.hyperbatch.sql.types.DataTypes;

HyperBatchSession hyperbatch = HyperBatchSession
  .builder()
  .appName("Java HyperBatch SQL UDF scalar example")
  .getOrCreate();

// Define and register a zero-argument non-deterministic UDF
// UDF is deterministic by default, i.e. produces the same result for the same input.
UserDefinedFunction random = udf(
  () -> Math.random(), DataTypes.DoubleType
);
random.asNondeterministic();
hyperbatch.udf().register("random", random);
hyperbatch.sql("SELECT random()").show();
// +-------+
// |UDF()  |
// +-------+
// |xxxxxxx|
// +-------+

// Define and register a one-argument UDF
hyperbatch.udf().register("plusOne",
  (UDF1<Integer, Integer>) x -> x + 1, DataTypes.IntegerType);
hyperbatch.sql("SELECT plusOne(5)").show();
// +----------+
// |plusOne(5)|
// +----------+
// |         6|
// +----------+

// Define and register a two-argument UDF
UserDefinedFunction strLen = udf(
  (String s, Integer x) -> s.length() + x, DataTypes.IntegerType
);
hyperbatch.udf().register("strLen", strLen);
hyperbatch.sql("SELECT strLen('test', 1)").show();
// +------------+
// |UDF(test, 1)|
// +------------+
// |           5|
// +------------+

// UDF in a WHERE clause
hyperbatch.udf().register("oneArgFilter",
  (UDF1<Long, Boolean>) x -> x > 5, DataTypes.BooleanType);
hyperbatch.range(1, 10).createOrReplaceTempView("test");
hyperbatch.sql("SELECT * FROM test WHERE oneArgFilter(id)").show();
// +---+
// | id|
// +---+
// |  6|
// |  7|
// |  8|
// |  9|
// +---+

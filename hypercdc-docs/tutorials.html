Tutorials

HyperCDC can be deployed in different ways depending on your infrastructure and use case. These tutorials help you take your first steps with HyperCDC by guiding you through end-to-end setups, from starting the required services to observing change events as data is modified in a source database.

Each tutorial is self-contained and uses Docker to run all necessary components, so you can follow along without installing anything beyond Docker on your machine.

Tutorial Description

Kafka Connect

Deploy HyperCDC connectors on Apache Kafka Connect to monitor a MySQL database and stream change events into Kafka topics.

Example projects

Beyond these tutorials, you can explore the HyperCDC Examples repository on GitHub. It contains a collection of demo projects and code samples that showcase different ways to use HyperCDC in various scenarios, including end-to-end architectures, integration with other technologies, and advanced configurations. These examples are a great resource for learning how to apply HyperCDC in real-world use cases and for experimenting with features beyond the scope of the introductory tutorials above.

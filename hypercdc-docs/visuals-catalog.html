Visual Assets & Diagrams Catalog

Central inventory of all 36 images, architecture diagrams, and figures across HyperCDC documentation.

How to Review & Replace Diagrams

  1. Click on any "View source asset" link to view the original Debezium diagram.
  2. Redraw or rebrand the diagram with HyperLake / HyperCDC logos and color palette.
  3. Save the new image into tools/custom-visuals/ using the Visual ID (e.g. tools/custom-visuals/fig-architecture-1.png).
  4. Re-run npm run import:hypercdc — the importer will automatically embed your new graphic in place of the placeholder!

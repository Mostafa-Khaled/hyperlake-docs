Upgrade Information

Following steps are necessary during updating to newer versions.

Upgrade to 2026.1.0​

  • The bundle installer now implements PostInstallCommandsProviderInterface from HyperMDM's InstallBundle. This means the post-install command bpt:aet:rebuild-tree -a is automatically executed during hypermdm:install when using Install Profiles. Manual execution of this command after hypermdm:bundle:install is still required as before.
  • The messenger transport DSN is now configurable via the %hypermdm.messenger.transport_dsn_prefix% container parameter instead of being hardcoded to doctrine://default. This allows the installer to wire the transport DSN from environment variables (e.g. HYPERMDM_MESSENGER_TRANSPORT_DSN_PREFIX).
  • Added support to PHP 8.5.
  • Removed support to PHP 8.3 and Symfony v6.

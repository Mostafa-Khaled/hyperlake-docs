Per-User Themes

Besides the system-wide default, each user can choose their own theme. A personal theme overrides the system default for that user only.

Choosing a Personal Theme​

The theme selector is available in the user's profile as well as in the user management, in the Appearance & Branding area below the avatar. The selector offers:

  • System default: follow whatever the administrator set as the system default theme. This is the default value.
  • any of the themes available in the Theme Manager.

Both the self-service profile (Edit profile) and the administrative user management persist the selection, so an administrator can set a theme on behalf of another user.

info

As with every theme change, a newly selected personal theme is applied on the next load of HyperMDM Studio, reload after saving to see it.

Resolution Order​

The active theme for a user is resolved from a single source of truth, on both the server and the client, in this order:

  1. The user's personal theme: when the user picked a concrete theme that still exists.
  2. The system default theme: when the user follows the system default (or their picked theme no longer exists).
  3. The HyperMDM Light theme: the ultimate fallback when no valid default can be resolved.

Anonymous visitors (for example on the login screen) have no user context and therefore always follow the system default theme.

This same resolution drives every theme-following surface, the token set (colors), the branding colors, the logo/thumbnails and the server-side preloader, so a user's chosen theme is reflected consistently, including on the initial paint before the HyperMDM Studio JavaScript runs.

Job Overview

The Job Overview page can be opened via Settings -> HyperMDM Copilot -> HyperMDM Copilot Job Runs and contains an overview about all jobs.

From this overview you can restart already finished jobs, cancel running jobs or get more information from the log file and the status of the job.

Set the permission to access this page per user or role in the Permissions Bundles section.

For Generic Execution Engine the permissions are:

  • HyperMDM Generic Execution Engine Bundle - Job Run Overview - to see their own job runs
  • HyperMDM Generic Execution Engine Bundle - See all Job Runs - to see all job runs

Open the detailed log for more information about the job and its steps.

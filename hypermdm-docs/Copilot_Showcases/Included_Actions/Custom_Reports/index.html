Custom Reports

This action provides a shortcut to open and view custom reports from the HyperMDM Copilot UI. HyperMDM Copilot lists one action per custom report you are permitted to view, independent of the context you are currently in.

Available Context​

For more information on context limitations, see Available Context in the HyperMDM Copilot documentation.

Multiselect: No selection needed Elements: None

Configuration​

No configuration needed. Execute the action directly from the HyperMDM Copilot UI if you have permission to view the report.

Requires the HyperMDM Custom Reports bundle to be installed. Without it, no report actions are offered and no error is shown.

Copilot Showcases

The Copilot Showcase Bundle ships example actions and action steps for HyperMDM Copilot. Install it to try out what Copilot can do, or use the included actions as a reference when building your own. The examples are reference implementations, not production code.

Features in a Nutshell​

  • A Regular Action that opens custom reports from the HyperMDM Copilot UI
  • Automation Action Steps that link elements to a new parent, debug job run data, and clean up temp files
  • Automation Action Steps that fine-tune Hugging Face models on data managed within HyperMDM, and start or pause the Hugging Face space that hosts the fine-tuning service
  • An Interaction Action that generates images with AI models based on an existing image

See Included Actions for what each of these action types means and the full list of examples.

Architecture Overview

This overview shows the available framework components. Configure each component under the hypermdm_customer_management_framework configuration node, and optionally swap in a custom implementation for any of them.

See the following chapters for details on each component, in the order most readers work through them:

  • Data entities: Customer (with the Customer Save Manager) and Customer Segments (with the Segment Manager)
  • Segment Assignment to HyperMDM elements
  • Activity Manager
  • Action Trigger Service
  • Customer Duplicates Service
  • MailChimp Integration
  • List Views
  • REST API Webservice
  • Integration with HyperMDM Personalization
  • Extending the Customer Management Framework

Special Triggers, Conditions, and Actions in the CMF Action Trigger Service

Besides HyperMDM Global Targeting Rules, CMF adds triggers, conditions, and actions that integrate targeting with the ActionTrigger service.

Trigger [Targeting] Segment Tracked​

Fires every time a segment is tracked to the Targeting Store, for example by a Global Targeting Rule, or when a user opens a document with an assigned segment. It has no further configuration options; it only stores the segment for later use in conditions and actions.

Trigger [Targeting] Assigned Target Group​

Fires every time a target group is assigned to the current user, either by a Global Targeting Rule or when a user opens a document with an assigned target group.

Use this trigger to modify customer objects, for example assigning segments, changing field values, or tracking activities, whenever a target group is assigned.

Condition [Targeting] Tracked Segments Count​

Checks how often the segment stored by the Segment Tracked trigger was tracked in the Targeting Storage. Optionally restrict the condition to specific segments by adding them to the list.

Condition [Targeting] Check Weight of Assigned Target Group​

Checks how often the target group stored by the Assigned Target Group trigger was assigned to the current user in the Targeting Storage (its weight). Optionally restrict the condition to specific target groups by selecting them in the list.

Action [Targeting] Add Tracked Segment​

Adds the segment stored by the Segment Tracked trigger to the customer object. Optionally remove other segments from the same group, increase the segment application counter, and make the action respect the customer object's profilingConsent attribute.

Action [Targeting] Add Target Group Segment​

If a segment is assigned to the target group stored by the Assigned Target Group trigger, adds it to the customer object. Optionally remove other segments from the same group, increase the segment application counter, and make the action respect the customer object's profilingConsent attribute.

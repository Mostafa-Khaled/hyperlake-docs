HyperMDM Customer Management Framework

HyperMDM manages any kind of data: unstructured digital assets and structured content. The most common structured content is product data and everything related to products, like categories, technologies, and brands. The built-in E-Commerce Framework supports building e-commerce applications and managing transactional data like orders. Besides products and transactions, the third major group of structured data is customer data.

The Customer Management Framework (CMF) for HyperMDM adds functionality for customer data management, segmentation, personalization, and marketing automation. It aggregates customer data and user profiles, enriches data, links social profiles, builds audience segments, triggers events, personalizes experiences, executes marketing automation, and more.

Like HyperMDM itself and the E-Commerce Framework, CMF is a framework for developers to build customer management solutions, tightly integrated into HyperMDM's core functionality.

Provided Functionality in a Nutshell​

  • Customer Data Management based on HyperMDM Data Objects.
  • Storage of Customer Activities from different data feeds.
  • Customer Segmentation based on data, activities and other criteria.
  • Duplicate detection and merging.
  • Enhancement of HyperMDM's on-site personalization.
  • Marketing Automation with built-in rule engine and triggers.
  • Default integration to external newsletter systems like MailChimp.
  • Rest API for integration of external systems for data import or export.

See the demo for a first impression, and the case studies for more complex solutions.

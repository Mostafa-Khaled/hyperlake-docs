HyperMDM Data Quality Management

The HyperMDM Data Quality Management bundle allows you to track and visualize your data quality.

Features in a Nutshell​

  • Compute a data quality score for your Data Objects based on customized rules.
  • Visualize your data quality score in the Data Object editor, grid and/or tree.
  • Provide improvement suggestions according to the computed score.
  • Add a precondition for computing data quality score only for certain kinds of Data Objects.
  • Visualize data quality scores on HyperMDM Studio Dashboards via dedicated widgets (requires the Studio Dashboards Bundle).

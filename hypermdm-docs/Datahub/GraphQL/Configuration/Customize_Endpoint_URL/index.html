Customizing the Endpoint

The standard endpoint is

/hypermdm-graphql-webservices/{clientname}?apikey={yourApiKey}

So if your configuration name is blogdemo and your apikey 123456 then your endpoint would be

/hypermdm-graphql-webservices/blogdemo?apikey=12345

Here is a configuration example showing how to override the standard endpoint:

# app/config/routing.yml

# Changing URL to the explorer environement
admin_hypermdmdatahub_config:
  path: /hypermdm-datahub-webservices-my-endpoint/explorer/{clientname}
  defaults: { _controller: HyperMDM\Bundle\DataHubBundle\Controller\GraphQLExplorerController::explorerAction }

# Changing endoint URL
admin_hypermdmdatahub_webservice:
  path: /hypermdm-graphql-webservices-my-endpoint/{clientname}
  defaults: { _controller: HyperMDM\Bundle\DataHubBundle\Controller\WebserviceController::webonyxAction }

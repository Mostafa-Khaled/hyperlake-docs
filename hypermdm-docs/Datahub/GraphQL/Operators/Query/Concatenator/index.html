Concatenator

Concatenates the values of the selected fields.

Configuration​

  • Label: Name for the field to use in the query.
  • Glue: The string that will be used to concatenate the values.

Example​

Request:

{
  getCar(id: 82) {
    id,
    ConcatYearCountry
  }
}

Response:

{
  "data": {
    "getCar": {
      "id": "82",
      "ConcatYearCountry": "1966-GB"
    }
  }
}

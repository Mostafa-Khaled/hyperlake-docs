Static Text

Adds the configured static text to the query.

Configuration​

  • Text: The text to add to the query.

Example​

Request:

{
  getCar(id: 82) {
    id,
    StaticTextForQuery
  }
}

Result:

{
  "data": {
    "getCar": {
      "id": "81",
      "StaticTextForQuery": "StaticTextForQuery"
    }
  }
}

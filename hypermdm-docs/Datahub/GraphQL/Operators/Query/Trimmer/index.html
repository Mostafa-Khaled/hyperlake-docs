Trimmer

Trims the value.

Configuration​

  • Label: Name for the field to use in the query.
  • Trim: Where to trim, either both, left, right or disabled.

Example​

Request:

{
  getCar(id: 82) {
    id,
    name,
    TrimmedName
  }
}

Response:

{
    "data": {
        "getCar": {
            "id": "82",
            "name": " Cobra 427 ",
            "TrimmedName": " Cobra 427"
        }
    }
}

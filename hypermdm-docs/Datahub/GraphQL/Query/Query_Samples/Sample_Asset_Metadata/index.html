Get Asset Metadata

Request​

Get the custom asset metadata for language de

{
  getAsset(id: 4, defaultLanguage: "de") {
    id
    fullpath
    type
    mimetype
    filesize
    metadata {
      name
      type
      data
      language
    }
  }
}

HyperMDM Datahub File Export

Datahub File Export publishes data stored in HyperMDM to flat CSV, XML or JSON files, configured in HyperMDM's Datahub. It targets recurring, scheduled exports.

Features​

  • Column-based schema configuration, the same field selection and transformers as a HyperMDM Studio data object grid
  • Export formats CSV, XML and JSON, extensible with custom types
  • Delivery to a local directory, SFTP, an HTTP endpoint, e-mail, a HyperMDM asset, or a token-guarded download URL
  • Exports triggered on save, by cron definition, from the CLI, or manually
  • Incremental exports: with the Update Current File conflict strategy, new rows are merged into the previously generated file instead of rebuilding it

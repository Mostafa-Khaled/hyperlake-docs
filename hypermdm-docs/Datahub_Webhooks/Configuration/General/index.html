General Tab

The General tab holds the basic settings of a webhook configuration.

The General tab of a webhook configuration

Active​

Only active configurations are evaluated when an event fires. Deactivate a configuration to park it without deleting it, or while you are editing it.

Log Level​

Selects what the configuration writes to the Logs tab. Select both levels to combine them, or leave the field empty to disable logging for this configuration.

  • Info: logs all available information, including the requests, the subscribers and the returned HTTP status codes.
  • Errors: logs errors and exceptions only.

Type and Name​

The adapter type and the configuration name are set when the configuration is created and cannot be changed here.

Description​

Free text describing the purpose of this configuration.

Group​

Free text used to group configurations in the Datahub tree on the left. Configurations sharing a group value appear together.

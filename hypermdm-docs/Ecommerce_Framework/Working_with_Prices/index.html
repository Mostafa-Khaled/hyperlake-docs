Working with Prices

Prices are an essential part of every E-Commerce solution. In order to be able to implement complex and very custom pricing schemes, the E-Commerce Framework has the concept of Pricing Systems. These Pricing Systems encapsulate all the logic of retrieving and calculating prices.

The Tax Management Component adds functionality for dealing with taxes and should be flexible enough to implement all kinds of tax structures.

With Pricing Rules and Vouchers marketing actions can be implemented.

For details on how to calculate with prices, see Calculate with Prices.

Technical Details

Migration of existing Data​

To add metadata collections to assets based on existing metadata, use following command. It will check for existing metadata entries if they have a prefix like License.something and then adds the corresponding collection (in this case License) to the asset.

php bin/console asset-metadata-class-definitions:populate

Assign collections to an asset programmatically​

Note: Metadata collections cannot be assigned to asset folders. If you attempt to assign a collection to an Asset\Folder, the operation will be silently skipped and a debug log entry will be written. Collections are only supported on actual assets (images, documents, videos, etc.).

To assign metadata collections to assets, use the Collections model as follows:

$col = new HyperMDM\AssetMetadataClassDefinitionsBundle\Model\Collections();

// assign Asset ID
$col->setAssetId(290);
// or assign Asset directly
$asset = new \HyperMDM\Model\Asset();
$asset->setKey('testImage.png');
$asset->setParentId(1);
$col->setAsset($asset);

$col->setCollections(["License", "Credits"]);

// either only apply collections to asset without saving it
$col->applyToAsset();

// or apply collection to asset and save the asset right away 
$col->save();

// setting metadata attributes itself is the same as with standard metadata
$asset = HyperMDM\Model\Asset::getById(290); 
$asset->addMetadata('CarImages.title', 'input', $title, $language);
$asset->save();

Get collections from an asset programmatically​

$asset = HyperMDM\Model\Asset::getById(290); 
$collections = \HyperMDM\AssetMetadataClassDefinitionsBundle\Model\Collections::getByAssetId($asset->getId());
$collectionNames = $collections->getCollections();

Add a definition programmatically​

$configuration = new \HyperMDM\AssetMetadataClassDefinitionsBundle\Model\Configuration();
$configuration->setName("License");
$configuration->setPrefix("License");
$configuration->setIcon("/bundles/hypermdmadmin/img/object-icons/02_red.svg");

$panel = new \HyperMDM\AssetMetadataClassDefinitionsBundle\Model\ClassDefinition\Layout\Panel();
$panel->setTitle("panel title");


$input = new \HyperMDM\AssetMetadataClassDefinitionsBundle\Model\ClassDefinition\Data\Input();
$input->setName("myinputfield");

$panel->addChild($input);

$configuration->setLayoutDefinitions($panel);
$configuration->save();

Option Provider for (Multi-)Select Fields​

Similar to option providers for select fields in data object classes you can implement an option provider for (multi-)select fields in metadata classes. The only difference is the interface which needs to be implemented:

<?php
use HyperMDM\AssetMetadataClassDefinitionsBundle\Model\ClassDefinition\Data\Data;
 
class MyOptionProvider implements \HyperMDM\AssetMetadataClassDefinitionsBundle\Model\ClassDefinition\DynamicOptionsProvider\SelectOptionsProviderInterface
{
    public function getOptions(array $context, Data $fieldDefinition): array
    {
        for($i=0; $i<100; $i++) {
            $options[] = [
                'key' => 'option_' . $i,
                'value' => 'Option ' . $i
            ];
        }
 
        return $options;
    }
}

HyperMDM Enterprise Asset Metadata

This extension adds Enterprise Asset Metadata. It allows configuring Asset metadata similarly to Data Object class definitions and adds additional data types for Asset metadata to HyperMDM.

Features in a Nutshell​

  • Introduction of Data Objects like visualization of Asset metadata.
  • Definition of Asset metadata structure in Asset class definitions (similarly to class definitions).
  • Possibility to assign multiple Asset metadata class definitions to each Asset.
  • Additional data types like multi-select, many-to-many relation, calculated values, and many more.
  • Same storage as for standard Asset metadata.

Asset Metadata Definition​

Required Permission: classes.

See System Permissions for details.

Asset Metadata Editor​

By default, the "Add predefined metadata button" gets disabled when using asset metadata class definitions bundle. In case you want to enable it, you can do so by setting

hypermdm_asset_metadata_class_definitions:
    show_add_predefined_metadata_button: true

configuration your /config/config.yaml file.

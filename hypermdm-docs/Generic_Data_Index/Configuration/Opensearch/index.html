OpenSearch Client Setup

info

Supported OpenSearch versions: >= 2.7 and < 3.0. OpenSearch 3 is not supported yet — see the HyperMDM OpenSearch Client for the supported client versions.

Configuration requires two steps:

  1. Configure an OpenSearch client via HyperMDM OpenSearch Client.
  2. Assign the client to the Generic Data Index bundle.
# 1. OpenSearch client configuration
hypermdm_open_search_client:
    clients:
        default:
            hosts: ['https://opensearch:9200']
            password: 'admin'
            username: 'admin'
            ssl_verification: false

# 2. Assign client to Generic Data Index
hypermdm_generic_data_index:
    index_service:
        client_params:
            client_name: default

For additional client options, see the HyperMDM OpenSearch Client documentation.

Disable Auto-Index Creation​

OpenSearch creates indices automatically when storing data to a nonexistent index. This causes incorrect indices and missing aliases. Disable this in your OpenSearch configuration:

action.auto_create_index=false

See #165 and #202 for details.

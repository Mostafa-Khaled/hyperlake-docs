Create a First Project

This tutorial walks you through building a simple product page with HyperMDM. You will upload assets, define a data model, and create CMS pages that combine both.

Prerequisites: A working HyperMDM installation from the Installation chapter.

What you will build:

  1. Directory Structure - Learn the project layout before making changes.
  2. Assets - Upload images and other files that your project will use.
  3. Data Objects - Define a product data model and create your first product.
  4. Documents - Create CMS pages with editable content and display your product data.

Platform Version

The HyperMDM Platform Version is a Composer meta-package (hypermdm/platform-version) that ensures all HyperMDM modules in a project use compatible versions. It does not install additional code. Instead, it defines version constraints (via Composer conflict rules) that prevent incompatible combinations of HyperMDM packages.

Both the hypermdm/skeleton and hypermdm/demo-enterprise installation packages include hypermdm/platform-version as a default dependency. No additional setup is needed for new projects.

Adding to an Existing Project​

To add the platform version to an existing HyperMDM project that does not yet use it:

docker compose exec php composer require hypermdm/platform-version

Composer may require you to adjust versions of other HyperMDM packages to satisfy the constraints defined by the platform version. Follow the instructions provided by Composer to resolve any conflicts.

Installing Additional HyperMDM Modules​

With the platform version in place, install additional HyperMDM modules using composer require:

docker compose exec php composer require hypermdm/<module-name>

Composer automatically resolves a version that is compatible with your platform version.

tip

If Composer cannot find a matching version, try adding :* as the version constraint:

docker compose exec php composer require hypermdm/<module-name>:*

Updating​

For updating to new platform versions (including bugfix updates, major version upgrades, and migration steps), see Updating HyperMDM.

Getting Started

This chapter walks you through setting up a working HyperMDM instance and building your first project.

  • Installation - Docker-based setup for both the empty skeleton and the demo enterprise package, plus system requirements and hosting configuration.
  • Product Registration - Register your HyperMDM instance and obtain a product key.
  • Create a First Project - A hands-on tutorial: upload assets, define a data model, and build CMS pages that bring it all together.

Accessing HyperMDM Assets via WebDAV

HyperMDM provides the option to access all assets via WebDAV. Open the following URL via your browser or WebDAV client: https://YOUR-DOMAIN/asset/webdav

Use any HyperMDM user as credentials. Permissions for asset access are based on the user's permissions.

Nginx Configuration​

Make sure to have the following changes in your project Nginx configuration:

location ~* ^(?!/admin|/asset/webdav)(.+?)\.(?:css|js|jpg|jpeg|gif|png|svg|ico|woff|woff2|xml)$ {

Content Management Features

HyperMDM provides a set of built-in content management capabilities that apply across documents, assets, and data objects. These features work consistently across element types, giving editors and developers a unified toolset for managing content lifecycles.

  • Versioning - Track changes, compare revisions, and restore previous states of any element
  • Notes & Events - Log changes and events independently from versioning
  • Tags - Classify and filter elements with custom taxonomies
  • Properties - Attach custom key-value metadata to elements
  • Scheduling - Automate publish, unpublish, and delete actions on a schedule
  • GDPR Data Extractor - Search and export personal data across data sources
  • Notifications - Send and receive in-app notifications between users and groups
  • Object Data Inheritance - Reduce maintenance with hierarchical data inheritance

Static Helpers

HyperMDM offers several static helper classes:

HyperMDM Tool​

The HyperMDM\Tool class is a collection of general service methods. See the class source file for the complete API.

Particularly useful methods:

  • isValidPath()
  • getValidLanguages()
  • getHostname()
  • getHostUrl()
  • classExists()
  • getMail()

E-Mail​

A convenience function that returns a preconfigured Symfony\Component\Mime\Email instance based on the HyperMDM email configuration:

$mail = HyperMDM\Tool::getMail($recipients, $subject);
// For any bundle or application, this avoids having to configure email settings independently.

Element Service​

The HyperMDM\Model\Element\Service class is a collection of service methods for elements (documents, assets, objects). See the class source file for the complete API.

Particularly useful methods:

  • getElementByPath()
  • getSafeCopyName()
  • pathExists()
  • getElementById()
  • getElementType()
  • createFolderByPath()
  • getValidKey()

Also see the sub-classes HyperMDM\Model\Asset\Service, HyperMDM\Model\Document\Service, and HyperMDM\Model\DataObject\Service.

Document Service​

A useful method for documents is HyperMDM\Model\Document\Service::render().

Use this helper to render a page outside of a view, for example to send emails.

Example:​
$optionalParams = ['foo' => 'bar', 'hum'=>'bug'];
$useLayout = true;
$content = Document\Service::render(Document::getById(2), $optionalParams, $useLayout);
echo $content;

Custom Extension Guides

This page indexes all extension guides across HyperMDM's three layers. Each guide indicates which layers it touches so you know what to expect before diving in.

Layer legend:

  • Core - PHP/Symfony: models, config, events, DI (hypermdm/hypermdm)
  • Backend - Studio Backend API: endpoints, adapters, response customization (studio-backend-bundle)
  • UI - HyperMDM Studio frontend: plugins, tabs, widgets, navigation (studio-ui-bundle)

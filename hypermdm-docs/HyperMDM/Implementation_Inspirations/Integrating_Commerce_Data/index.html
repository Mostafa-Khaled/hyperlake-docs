Integrating Commerce Data With Content

A common requirement in e-commerce projects is integrating content and commerce data. HyperMDM's integrated approach provides several tools to combine both seamlessly.

One of these tools are Renderlets, which provide a great way to integrate dynamic object (thus commerce) content to HyperMDM documents.

Follow the steps to create a product teaser similar to the one in the HyperMDM demo.

Create Area Brick MyProductTeaser with Renderlet​

MyProductTeaser Implementation

<?php

namespace App\Document\Areabrick;

class MyProductTeaser extends AbstractAreabrick
{
    public function getName(): string
    {
        return 'My Product Teaser';
    }
}

MyProductTeaser Template

<div class="row">
    {% for i in hypermdm_block('teaserblock').iterator %}
        {{ hypermdm_renderlet('productteaser', {
            controller: 'shop',
            action: 'productCell',
            width: 270,
            height: 370,
            title: 'Drag a product here',
            editmode: editmode
        }) }}
    {% endfor %}
</div>

Create Controller and Action for Teaser Content​

Controller Action

    public function productCellAction(Request $request): Response
    {
        $id = $request->attribute->getInt('id');
        $type = $request->attribute->get('type');

        if ($type === 'object') {
            $product = Product::getById($id);

            return $this->render('product/product_cell.html.twig', ['product' => $product]);
        }

        throw new \Exception('Invalid Type');
    }

Limitations​

Nesting of Data Types​

Data types cannot be arbitrarily nested within each other. For example, do not nest blocks within blocks or localized fields within localized fields. Additionally, data type containers such as blocks or field collections cannot be nested more than two levels deep.

For instance, the following structure is not allowed:

-- Field Collection
    -- Block
        -- Localized Field
            -- Input field

However, the following structure is allowed:

-- Field Collection
    -- Block
        -- Input field

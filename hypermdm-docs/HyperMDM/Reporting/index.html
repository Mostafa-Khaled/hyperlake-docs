Reporting

HyperMDM provides reporting tools for querying, visualizing, and exporting data from across the system. These range from SQL-based tabular reports to interactive dashboards and statistics views.

Custom Reports​

SQL-based tabular and chart reports with filtering, CSV/XLSX export, and extensible data source adapters. Build reports against any database table or custom data source, configure column visibility, drill-down filters, and chart visualizations directly in HyperMDM Studio.

Custom Reports Documentation

Statistics Explorer (Enterprise)​

Interactive data aggregation, pivot tables, and charting across HyperMDM data sources. Statistics Explorer also integrates as a Custom Report adapter for embedding aggregated views into the standard reporting interface.

  • Statistics Explorer Documentation
  • Custom Report Integration

Dashboards (Enterprise)​

Configurable dashboards with portlets in HyperMDM Studio. Combine reports, charts, and key metrics into personalized dashboard views.

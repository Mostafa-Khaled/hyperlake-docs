Workflow Reporting

Depending on the marking store of workflows, different reporting methods are available. See marking store docs for details.

Using state_table and Custom Reports​

Use custom reports for workflow place reporting, filtering, exporting, and directly opening related elements. This way, follow and monitor workflows and the progress of documents, assets, and objects.

Using single_state, data_object_multiple_state and data_object_splitted_state together with Object Grid​

Since single_state (and others) stores place information in data object attributes, HyperMDM default object grids handle workflow reporting on HyperMDM Objects. Create a corresponding grid configuration and use default filtering and sorting functionality.

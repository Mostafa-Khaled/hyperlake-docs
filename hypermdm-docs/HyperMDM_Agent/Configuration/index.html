The merge model at a glance​

Every agent and every skill comes from one of three layers. Higher layers override lower layers by name - full-object replacement, no field-level merging.

Layer (highest wins)Who manages itWhere it lives
HyperMDM Studio editsAdministratorsSettingsStore (default) or var/config/agent/*.yaml
Container configProject codehypermdm_agent.agents.definitions, auto-prepended YAML
Bundle presetsBundle authorshypermdm_agent.agents.paths / skills.paths in bundles

In practice: a bundle ships sensible defaults; a project overrides any of them from code; an administrator tweaks anything further at runtime from HyperMDM Studio without touching code. Upgrading a bundle never clobbers an administrator's edits. Every entry in HyperMDM Studio carries a bundle or user source badge.

Full mechanics - export endpoint, reload paths, skill materialization - in Architecture → Configuration System.

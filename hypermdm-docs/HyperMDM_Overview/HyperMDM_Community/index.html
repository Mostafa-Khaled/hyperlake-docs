HyperMDM Community

HyperMDM is developed as an open-core project. The full source code of all modules is available on GitHub, licensed under the HyperMDM Open Core License (POCL). Community contributions are an important part of the product's development.

Contributing​

HyperMDM actively reviews and accepts pull requests from the community. Contributions can range from bug fixes to feature improvements.

  • Bug fixes: Fork the repository, fix the issue on the latest maintenance branch, and submit a pull request
  • Features and improvements: Submit PRs against the main branch. For larger changes, reach out before starting implementation
  • Security issues: Report via the dedicated security form, not through public issues
  • Contributor License Agreement (CLA): Must be signed before a PR can be merged

The coding standards are defined in .php-cs-fixer.dist.php and verified via PHPStan. See the full Contributing Guidelines for details.

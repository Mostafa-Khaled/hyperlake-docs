HyperMDM Editions

HyperMDM follows an open-core licensing model. The core framework and a set of extensions are available under the HyperMDM Open Core License (POCL). Additional modules are available through commercial editions, each building on the previous tier.

Edition Overview​

EditionDescription
CommunityThe core of HyperMDM, available free of charge. Provides access to PIM, MDM, DAM, and DXP capabilities. Intended for non-production environments, academic institutions, non-profit organizations, and commercial entities with annual revenue under EUR/USD 5 million. Includes the core framework, HyperMDM Studio, Data Hub, Data Importer, and Quill editor.
ProfessionalEverything in Community, plus the TinyMCE WYSIWYG editor. Designed for organizations that do not meet the criteria of the Community edition and need a commercially licensed platform.
EnterpriseIncludes all available modules. See the availability table below for the complete list.
Enterprise PaaSEnterprise edition with managed cloud infrastructure. Includes all Enterprise modules plus managed hosting, automated deployments, and infrastructure operations.

Licensing​

All editions use the HyperMDM Open Core License (POCL) for the core components. Commercial editions (Professional, Enterprise, Enterprise PaaS) require a subscription. For pricing details, see hypermdm.com/en/pricing.

HyperMDM Modules

HyperMDM's functionality is organized into modules, each distributed as a separate Composer package. All HyperMDM source code is licensed under the HyperMDM Open Core License (POCL). For details on which modules are included in each edition, see HyperMDM Editions.

HyperMDM Core​

ModuleDescription
HyperMDM Core FrameworkCore framework providing Documents, Data Objects, Assets, and all foundational services
Studio BackendCentral hub for API endpoints, providing a unified interface based on OpenAPI for all backend operations
Studio UIAdministration interface for HyperMDM, built on React and relying on the Studio Backend API
Generic Data IndexCentralized indexing and search for Assets, Data Objects, and Documents via OpenSearch or Elasticsearch
Quill EditorQuill 2.x WYSIWYG editor integration for Documents, Data Objects, and Shared Translations
TinyMCE EditorTinyMCE WYSIWYG editor integration for Documents, Data Objects, and Shared Translations

Data Onboarding & Distribution​

ModuleDescription
DatahubData delivery and consumption platform integrating different input and output channel technologies into a configurable system
Data ImporterNo-code data import from CSV, XLSX, JSON, and XML sources into HyperMDM Data Objects via configurable mappings
Datahub File ExportAutomated publishing of HyperMDM data to CSV, XML, or JSON files via Datahub configurations
Datahub Simple RESTRead-only REST API for Assets and Data Objects, indexed in OpenSearch/Elasticsearch for query performance and scalability
Datahub WebhooksWebhook notifications for events on Assets, Documents, Data Objects, and workflows, allowing external systems to subscribe to HyperMDM events

Productivity​

ModuleDescription
Backend Power ToolsBulk editing, batch operations, and productivity tools for managing large datasets in HyperMDM Studio
Direct EditEdit HyperMDM Assets locally in a preferred editor and upload changes directly back to HyperMDM
Workflow DesignerVisual designer for the HyperMDM workflow engine

Automation​

ModuleDescription
CopilotLLM-based assistant for executing actions within HyperMDM, automating tasks like content generation, translation, and data enrichment
Copilot ShowcasesCollection of action steps and examples demonstrating HyperMDM Copilot capabilities
Workflow AutomationExport Datahub configuration blueprints to workflow automation engines like n8n

Portals & Dashboards​

ModuleDescription
Studio DashboardsConfigurable dashboards with widgets for data visualization and KPIs
Portal EngineConfigurable Asset and Product Experience Portals for external sharing and collaboration
Statistics ExplorerStatistics tool for data exploration and report creation, integrated into HyperMDM

Advanced Data Management​

ModuleDescription
Headless DocumentsHeadless document management with content accessible via Datahub endpoints for frontend applications
Asset Metadata Class DefinitionsClass-based metadata schemas for Assets, configured similarly to Data Object class definitions
Data Quality ManagementData quality tracking and visualization with configurable rules
Web-to-PrintWeb-to-print document creation and PDF conversion
Customer Management FrameworkCustomer data management with segmentation, activity tracking, and marketing automation

Marketing & Personalization​

ModuleDescription
PersonalizationBehavioral targeting and personalization engine for visitor profiling and targeted content delivery

Integrations​

ModuleDescription
OpenID ConnectSSO for HyperMDM backend login via OpenID Connect providers
Translation Provider InterfacesTranslation jobs sent to external translation APIs for processing
Datahub ProductsupIntegration with Productsup for product data syndication to marketplaces and marketing channels

E-Commerce​

ModuleDescription
E-Commerce FrameworkE-commerce framework handling product structures, pricing, availability, and customer groups

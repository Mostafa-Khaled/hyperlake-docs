HyperMDM PaaS

What is HyperMDM PaaS and how does it work?​

HyperMDM Platform-as-a-Service is a cloud platform for building, running and scaling your HyperMDM applications, provided by the top-notch Upsun technology stack. It also includes the license for HyperMDM Enterprise Edition and therefore opens up all the possibilities of the extensive features and services.

For a more detailed overview of features, pricing and ordering, please visit our product page.

Prerequisites​

Before you start, ensure you have the following:

Required Credentials​

  • HyperMDM License Token - Found on your license certificate
  • Composer Repository URL - Your custom repo.hypermdm.com URL from the license certificate (e.g., https://repo.hypermdm.com/YOUR_REPO_NAME/)
  • HyperMDM PaaS Console Account - Access to the HyperMDM PaaS Console

Required Tools​

  • PHP 8.4+ with Composer installed (or Docker as an alternative)
  • Git - For version control
  • HyperMDM Cloud CLI (hypermdm-cloud) - Install separately (installation guide
  • Docker (optional) - For local development with containerized environments

Required Knowledge​

  • Upsun Concepts - Familiarity with the Upsun platform is essential. Since there are no major differences between HyperMDM PaaS and Upsun, this documentation serves as an on-top guide to the Upsun docs, outlining the specifics of how to run HyperMDM on Upsun.
  • Basic HyperMDM Knowledge - Understanding of HyperMDM concepts and workflows (see HyperMDM Academy for learning resources)

Events

Within the portal engine the following events are triggered to allow influencing certain behaviors. All of these events are triggered via the Symfony event dispatcher. Therefore, the related Symfony Events and Event Listeners documentation is a good starting point if you do not know how it works already.

The events do not have dedicated event names but are represented by there full class name and namespace. You will find one example how to listen to a portal engine event here.

List of Events​

Take a look at the event PHP classes. You will find a hint for the purpose of the events as PHP doc. Additionally, the getters and setters describe which attributes can be influenced by event listeners.

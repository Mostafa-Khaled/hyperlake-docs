Login

Before using any portal created with the portal engine, users have to login into the system.

Users are created and configured with HyperMDM data objects and can have different feature, portal and data access permissions. For details see the user management in the administration part.

In addition it is possible to integrate SSO via OpenID Connect. For each configured OpenID Connect provider, the login page provides an additional login button that connects to the corresponding provider for login. Details see also OpenID Connect Integration.

User profile page and password recover functionality exist in every portal.

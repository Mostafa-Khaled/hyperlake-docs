HyperMDM Portal Engine

HyperMDM Portal Engine allows creating outstanding Asset Experience Portals and Product Experience Portals just by configuration - no coding needed.

The created portals provide lots of out-of-the box features and allow UI customization by configuration. Additionally, it is possible to further adapt and extend the portals with custom code.

Sample portal generated with HyperMDM Portal Engine

Features in a Nutshell​

  • Multiple portals configuration in one system for different target groups.
  • Data visualization from Assets and Data Objects managed in HyperMDM.
  • Searching, filtering for, and navigating through data.
  • Management of Assets by uploading, updating, deleting and editing Assets metadata.
  • Different formats available for downloading data.
  • Gathering of data that belong together in collections or adding them in carts to download them jointly in a zip file.
  • Data or data collection sharing with other users and external stakeholders.
  • Permission management based on users and roles, including SSO integration via OpenID Connect.
  • Multi-language and multi-tenant support.

Installation

Requirements​

  • PHP 8.5
  • HyperMDM 2026.1 or later
  • Studio UI bundle 0.12.9 or later

Install​

composer require hypermdm/quill-bundle

Enable the bundle in config/bundles.php:

use HyperMDM\Bundle\QuillBundle\HyperMDMQuillBundle;
// ...

return [
    // ...
    HyperMDMQuillBundle::class => ['all' => true],
    // ...
];

For toolbar and theme options, see Configuration. If you are replacing TinyMCE, see Migration from TinyMCE.

Elasticsearch configuration

The ElasticsearchAdapter needs an Elasticsearch cluster to work.

Elasticsearch client configuration takes place via HyperMDM Elasticsearch Client Bundle

# Configure an Elasticsearch client 
hypermdm_elasticsearch_client:
    es_clients:
        default:
            hosts: ['elastic:9200']
            username: 'elastic'
            password: 'somethingsecret'
            logger_channel: 'hypermdm.elasicsearch'

HyperMDM Elasticsearch Client Bundle registers symfony services for each configured Elasticsearch client which can be used for data sources (see above) and event trackers.

Configuration above creates a default client which is registered as service hypermdm.elasticsearch_client.default.

For further configuration options (like authentication) have a look at HyperMDM Elasticsearch Client Bundle.

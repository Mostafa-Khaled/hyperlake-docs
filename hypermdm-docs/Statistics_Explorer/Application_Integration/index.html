Application Integration

Statistics Explorer provides a UI for configuring and displaying reports. To use it, it must be embedded into an existing host application that provides the necessary execution context. This allows seamless integration into portals or other applications where reporting and data analysis are required.

Setup Requirements​

Before embedding Statistics Explorer, the following configurations must be completed:

  • User Provider – Define how users are authenticated and authorized.
  • Routes – Configure access paths for the Statistics Explorer UI.
  • Data Sources – Set up the available data sources for report generation.

Integration Options​

Once the basic setup is done, Statistics Explorer can be embedded into the host application in two ways:

  • Statistics Explorer UI – A full-featured interface for creating, configuring, and managing reports. It includes options for defining data sources, selecting filters, generating visualizations, and saving or sharing reports.
  • Statistics Loader – A read-only view for displaying preconfigured reports and charts. This is useful for presenting data without allowing modifications.

Selecting the appropriate integration method depends on whether users need full report management capabilities or just access to pre-generated results.

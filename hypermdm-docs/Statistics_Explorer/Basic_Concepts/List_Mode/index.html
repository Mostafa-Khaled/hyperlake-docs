List Mode

The List Mode allows creating simple, structured listings with filtering and sorting. It is ideal for retrieving and displaying specific records from a dataset without aggregation.

Example Use Cases:​

  • List assets with expiring licenses.
  • Identify products without images.
  • Find products that do not meet data quality standards.
  • Display assets with missing metadata.

Configuration Options​

Find detailed documentation on configuration options below.

Columns​

Columns define the attributes displayed in the report’s result table. The available attributes are determined by the selected data source.

For example, when listing assets, columns may include ID, Name, and Metadata Attributes to provide relevant details.

Field Settings​

Each selected attribute has additional field settings that control how data is displayed and processed. Available settings depend on the data source type, field type, and column position in the report (aggregation/column/first/last).

Field settings cover aspects such as result order, maximum results, and labels.

Filters​

Filters allow refining the dataset before results are generated. They help narrow down the data based on specific conditions, ensuring that reports focus only on relevant information.

Once a data source is selected, available filter options are determined by the data source type and field types. Filters can be applied to limit data based on attributes such as date ranges, categories, numeric thresholds, or text-based conditions.

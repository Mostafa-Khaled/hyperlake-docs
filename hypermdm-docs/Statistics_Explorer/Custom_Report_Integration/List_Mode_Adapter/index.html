List Mode Adapter

The List Mode Adapter enables generating reports in List Mode within Custom Reports. It allows displaying structured listings with filtering and sorting options.

Configuration Options​

The adapter provides the following configuration options:

  • Columns – Define which attributes should be displayed as columns in the report.
  • Field Settings – Configure detailed options for each field, such as sorting, labels, and max results.
  • Filters – Apply filters to refine the dataset before displaying the results.

For detailed information, refer to the List Mode documentation.

Limitations​

The List Mode Adapter has the following limitations in the report view:

  • No Paging Support – The report view does not support pagination.

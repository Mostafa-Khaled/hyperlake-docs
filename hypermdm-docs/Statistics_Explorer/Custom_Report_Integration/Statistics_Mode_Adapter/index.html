Statistics Mode Adapter

The Statistics Mode Adapter enables generating reports in Statistics Mode within Custom Reports. It allows aggregating data, applying filters, and structuring reports using pivot tables and metrics.

Configuration Options​

The adapter provides several configuration options to define how data is processed and displayed:

  • Aggregations & Columns – Configure how data is grouped and define additional column attributes for pivot tables.
  • Field Settings – Adjust detailed settings for each field, such as sorting, result limits, and metric calculations.
  • Filters – Define filters that apply before aggregations are calculated, refining the dataset for more precise reporting.

For detailed information, refer to the Statistics Mode documentation.

Limitations​

Following limitations apply in the reports view:

  • No Column Ordering – Columns cannot be manually reordered in the report view.
  • No Drill-Down Filters for Dates – Date-based attributes do not support drill-down filtering.
  • No Filters for Matrix Columns – Filters and drill-down filters cannot be applied to column attributes.
  • No Paging Support – The report view does not include paging functionality.

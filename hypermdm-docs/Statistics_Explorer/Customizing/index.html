Customizing

Adapt Statistics Explorer to specific requirements through event listeners and configuration settings.

Available Customization Options:​

  • Customizing Results via Events – Modify report results dynamically using event listeners.
  • Providing Predefined Report Configurations – Define and load report configurations via settings or events.
  • Adding Data Sources During Runtime – Register additional data sources dynamically using events.
  • Custom Report Data Source Events – Adjust the data sources, fields and field settings that HyperMDM Studio offers in the custom report configuration.

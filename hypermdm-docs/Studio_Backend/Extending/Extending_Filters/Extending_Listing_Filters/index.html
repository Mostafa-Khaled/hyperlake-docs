Extending Listing Filters

Listing Filters add filter logic to classic HyperMDM Listing classes.

Adding a Listing Filter​

Implement HyperMDM\Bundle\StudioBackendBundle\Listing\Filter\FilterInterface and register the service with the tag hypermdm.studio_backend.listing.filter.

AbstractListing vs CallableListingInterface​

Not all listings support the same filtering API:

  • AbstractListing: Use addConditionParam() to chain multiple filters. Do not use setCondition() as it overwrites all existing conditions.
  • CallableListingInterface: Only supports setFilter(), so all filtering logic must be combined into a single filter (see the properties filter for an example).

Frontend Widget Type

The frontend side of a custom widget type is a TypeScript class that implements the dashboards widget-type contract. It controls how the widget is displayed, what configuration form elements are shown, and which visualization options are available for which layout slots.

Widget Type Contract​

Inside the Studio Dashboards Bundle source code, built-in widgets extend the internal DynamicTypeWidgetTypeDefinitionAbstract class.

For external bundles, do not import deep module paths from hypermdm_studio_dashboards_bundle/.... The dashboards remote exposes only its root plugin entry point, not internal source modules.

Implement the same method contract in your own class:

import { injectable } from 'inversify'

type WidgetTypeContract = {
    id: string
    getWidgetComponent: (...args: any[]) => React.ReactElement
    getWidgetHeaderComponent: (...args: any[]) => React.JSX.Element | null
    getWidgetEditModeView: (...args: any[]) => any[]
    getWidgetAllowedVisualizations: (...args: any[]) => any
    getWidgetIsAllowedBySlot: (...args: any[]) => any
    getWidgetAdditionalFormElements: (...args: any[]) => React.FC<any> | null
}

@injectable()
export class DynamicTypeWidgetTypeTopAssets implements WidgetTypeContract {
    readonly id = 'top_assets'
    // ...
}

The id must match the string returned by getSupportedWidgetType() in the backend classes.

Methods to Implement​

getWidgetComponent()​

Returns the React element rendered inside the widget card.

getWidgetComponent ({ config, data, layoutConfig }: IWidgetConfig): ReactElement {
    return <TopAssetsWidget config={ config } data={ data } />
}

getWidgetHeaderComponent()​

Returns an optional React element rendered in the widget header area, or null for the default header.

getWidgetHeaderComponent (): React.JSX.Element | null {
    return null
}

getWidgetEditModeView()​

Returns a list of label/value pairs shown in the widget's read-only edit-mode summary.

getWidgetEditModeView (config: any): IWidgetEditModeViewItem[] {
    return [
        { label: 'dashboards.widget.visualization', value: config.visualization }
    ]
}

getWidgetAllowedVisualizations()​

Filters which visualization options are available for a given layout slot. Return the full visualizationData array unchanged to allow all options everywhere.

getWidgetAllowedVisualizations ({ slotData, visualizationData }: IWidgetAllowedVisualizations): IWidgetSelectOption[] {
    // Only allow table visualization in single-column slots
    return this.filterWidgetConfigBySlot(visualizationData, slotData, {
        bar_chart: [{ column: 2 }, { column: 3 }]
    })
}

The helper filterWidgetConfigBySlot(visualizationData, slotData, filters) removes entries whose value key appears in filters but whose slot does not match any of the allowed slot constraints. Omit a visualization key from filters to allow it everywhere.

getWidgetIsAllowedBySlot()​

Returns true if this widget type may be placed in the given slot at all.

getWidgetIsAllowedBySlot ({ slotData }: IWidgetIsAllowedBySlot): boolean {
    return slotData.column > 1   // require at least a 2-column wide slot
}

getWidgetAdditionalFormElements()​

Returns an optional React component that is appended to the widget configuration form. Use it to expose widget-specific settings (e.g. element type filters, page size).

getWidgetAdditionalFormElements (): React.FC<any> | null {
    const AdditionalFormElements: React.FC<any> = () => {
        const { t } = useTranslation()
        return (
            <Form.Item name="limit">
                <InputNumber min={ 1 } max={ 50 } defaultValue={ 10 } />
            </Form.Item>
        )
    }
    return AdditionalFormElements
}

Return null if no additional form fields are needed.

Full Example​

import React, { type ReactElement } from 'react'
import { injectable } from 'inversify'

type IWidgetConfig = { config: any, data: any, layoutConfig: any }
type IWidgetAllowedVisualizations = { slotData: { row: number, column: number }, visualizationData: IWidgetSelectOption[] }
type IWidgetEditModeViewItem = { label: string, value: any }
type IWidgetIsAllowedBySlot = { slotData: { row: number, column: number } }
type IWidgetSelectOption = { value: string, label: string }
import TopAssetsWidget from '../types/top-assets'

@injectable()
export class DynamicTypeWidgetTypeTopAssets {
    readonly id = 'top_assets'

    getWidgetComponent ({ config, data }: IWidgetConfig): ReactElement {
        return <TopAssetsWidget config={ config } data={ data ?? [] } />
    }

    getWidgetHeaderComponent (): React.JSX.Element | null {
        return null
    }

    getWidgetEditModeView (config: any): IWidgetEditModeViewItem[] {
        return [{ label: 'dashboards.widget.visualization', value: config.visualization }]
    }

    getWidgetAllowedVisualizations ({ slotData, visualizationData }: IWidgetAllowedVisualizations): IWidgetSelectOption[] {
        return this.filterWidgetConfigBySlot(visualizationData, slotData, {
            bar_chart: [{ column: 2 }, { column: 3 }]
        })
    }

    getWidgetIsAllowedBySlot ({ slotData }: IWidgetIsAllowedBySlot): boolean {
        return slotData.column > 1
    }

    getWidgetAdditionalFormElements (): React.FC<any> | null {
        return null
    }
}

Getting Started With Your First Plugin

The HyperMDM Studio plugin system allows developers to extend the functionality of HyperMDM Studio by creating custom plugins.

Plugins provide additional tools, widgets, or settings that enhance the user experience within HyperMDM Studio.

Getting started​

Create your HyperMDM Studio Plugin either in a HyperMDM Bundle (the way to go when your Studio Plugin should be reused in multiple HyperMDM installations), or directly in your HyperMDM App without creating a HyperMDM Bundle.

Setup JS assets​

To get started, create an assets root folder for your application (e.g. /assets) and install the HyperMDM Studio UI npm package, which offers full TypeScript support for the HyperMDM SDK.

npm install @hypermdm/studio-ui-bundle react@18.3.x react-dom@18.3.x
tip

To adapt early to new features, use the canary release that includes typings for the most recent .x-branch updates:

npm install @hypermdm/studio-ui-bundle@canary react@18.3.x react-dom@18.3.x
warning

Ensure the React version matches the React version HyperMDM Studio uses.

With our dependency in place we should now setup our bundling process. We recommend Rsbuild. Of course you also can choose your preferred custom bundling process, or add additional steps like linting etc. to the bundling process.

For rsbuild you need to add additional rsbuild dependencies to bundle your application:

npm add @rsbuild/core @rsbuild/plugin-react @module-federation/rsbuild-plugin -D

Then create a rsbuild.config.ts file in your assets root folder to configure the bundling: Example Rsbuild configuration

Additionally, we need to create a main.ts in a source folder (e.g. /assets/js/src) which serves as the entrypoint in the rsbuild and is referenced in the rsbuild.config.ts. Start with an empty file.

Update your package.json with the following commands: npm commands

Create the main plugin file index.ts and export it in the plugins.ts file in the source folder (e.g. /assets/js/src). Use our boilerplate to get started quickly: Plugin boilerplate Plugins Export example file

The assets folder should now contain these files:

assets
 |- js
    |- src
        |- index.ts
        |- main.ts
        |- plugins.ts
 |- node_modules
 |- package-lock.json
 |- package.json
 |- rsbuild.config.ts

This will register a simple plugin in HyperMDM Studio.

Now that everything is in place, it’s time to bundle the files. Run:

npm run build        # production
npm run dev          # development with watch
npm run dev-server   # development with live reloading

When the command is finished you should have a few new files in your ./public/build directory.

Register JS Entrypoint​

Most important is the generated entrypoints.json manifest in ./public/build, which tells HyperMDM where to find the generated frontend files. Register a WebpackEntryPointProviderInterface service in the HyperMDM service container:

  • WebpackEntryPointProvider.php
  • services.yaml

Check​

Finally, we should ensure that our plugin is working. Place a console.log() in one of the plugin methods. Quickly recompile the app by using one of the npm commands listed above. On success, you should see your console.log().

Installation of the Studio UI Bundle

Bundle Installation​

  1. Verify these prerequisites:
  • GenericExecutionEngineBundle installed and activated
  • GenericDataIndexBundle installed and activated
  • StudioBackendBundle installed and activated
  1. Install the required dependencies:
composer require hypermdm/studio-ui-bundle
  1. Add the bundle to config/bundles.php:
use HyperMDM\Bundle\StudioUiBundle\HyperMDMStudioUiBundle;
// ...
return [
    // ...
    HyperMDMStudioUiBundle::class => ['all' => true],
    // ...
];
  1. Install the bundle:
bin/console hypermdm:bundle:install HyperMDMStudioUiBundle

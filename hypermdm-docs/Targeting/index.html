Behavioral Targeting and Personalization

HyperMDM includes an integrated behavioral targeting and personalization engine. It profiles visitors based on their behavior, assigns them to target groups, and delivers personalized content to those target groups, so you can show customers contextual, relevant content.

Before starting with Personalization, get familiar with these core concepts:

  • Target Group
  • Global Targeting Rule
  • Personalized Document Content

After that, install the bundle and get started personalizing content.

For details on extending HyperMDM's targeting engine and using targeting information in custom modules, see the Development Documentation.

Features in a Nutshell​

  • Add behavioral targeting and personalization to HyperMDM.
  • Define target groups.
  • Set up visitor profiling with rules based on visitor behavior.
  • Create personalized versions of documents for defined target groups.
  • Deliver personalized content to target groups.

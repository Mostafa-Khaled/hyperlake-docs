Installation

Requirements​

  • PHP 8.4 or 8.5
  • HyperMDM 2026.1 or later in the 2026 release line (constraint ^2026.1), Professional or Enterprise Edition
  • hypermdm/studio-ui-bundle and hypermdm/studio-backend-bundle, same constraint (^2026.1)

Install​

composer require hypermdm/tinymce-bundle

Composer pulls in the editor itself through the tinymce/tinymce dependency. The bundle declares ^7.9.3 || ^8.7.0, so Composer resolves the major version. To pin one, require it explicitly in your project:

composer require tinymce/tinymce:^8

Enable the bundle in config/bundles.php:

use HyperMDM\Bundle\TinymceBundle\HyperMDMTinymceBundle;
// ...

return [
    // ...
    HyperMDMTinymceBundle::class => ['all' => true],
    // ...
];

Install the bundle:

bin/console hypermdm:bundle:install HyperMDMTinymceBundle

For toolbar options and global defaults, see Configuration. If you are replacing Quill, see Migration from Quill.

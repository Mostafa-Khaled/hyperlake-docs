TinyMCE WYSIWYG Editor

Integrates TinyMCE v7 and v8 as WYSIWYG editor into HyperMDM. TinyMCE provides rich-text editing for documents, data objects, and shared translations.

Features​

  • Rich-text editing based on TinyMCE with a configurable toolbar including undo/redo, formatting, tables, lists, and code editing
  • WYSIWYG support for document editables, data object fields, and shared translations
  • Per-field toolbar configuration through Twig editables
  • Global editor defaults through Symfony configuration (hypermdm_studio_ui)
  • Optional cloud loading via Tiny Cloud CDN
  • Unsafe embed conversion enabled by default (convert_unsafe_embeds: true)

Development

Extension points for developers who need to change how the bundle renders PDFs or what its HyperMDM Studio responses contain.

  • Events - PDF generation events and Studio pre-response events, with their payloads.

For a worked example that combines both PDF generation events, see Extending PDF Creation Config for PDF/X Conformance.

Custom PDF processors extend the abstract HyperMDM\Bundle\WebToPrintBundle\Processor class. Register the fully qualified class name as the tool in the web-to-print settings, as described in Document Types and Available PDF Processors.

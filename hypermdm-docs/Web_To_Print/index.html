HyperMDM Web to Print Module

Adds the ability to create web-to-print documents in HyperMDM and to convert them into a PDF.

Features in a Nutshell​

  • Add web2print support for generating PDFs to HyperMDM.
  • Add new HyperMDM-specific Document types to create print documents with HyperMDM Documents (and all related concepts and features).
  • Allow creating single pages and whole catalogs with chapters, subchapters and table of contents.
  • Integrate different adapters to render documents to PDFs: Gotenberg, PDF reactor.

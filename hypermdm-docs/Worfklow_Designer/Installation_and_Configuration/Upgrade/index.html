Upgrade Notes

Upgrade to 2026.1.0​

General​

  • Added support for PHP 8.5.
  • Removed support for PHP 8.3 and Symfony v6.
  • Removed support for hypermdm/admin-ui-classic-bundle in favor of HyperMDM Studio.

Removed Admin Classic / ExtJS Support​

  • HyperMDMWorkflowDesignerBundle no longer implements HyperMDMBundleAdminClassicInterface and no longer uses BundleAdminClassicTrait. The methods getJsPaths() and getCssPaths() returning ExtJS assets have been removed.
  • HyperMDMAdminBundle is no longer added as a dependent bundle.
  • The following legacy ExtJS JS/CSS assets have been removed:
    • public/js/hypermdm/startup.js
    • public/js/hypermdm/ext_extensions.js
    • public/js/hypermdm/configuration/configurationItem.js
    • public/js/hypermdm/configuration/configurationTree.js
    • public/js/hypermdm/configuration/item/additionalField.js
    • public/js/hypermdm/configuration/item/globalActionSettings.js
    • public/js/hypermdm/configuration/item/placeSettings.js
    • public/js/hypermdm/configuration/item/transitionSettings.js
    • public/css/admin.css
    • public/css/fixes.css

Removed Legacy Controllers and Routing​

  • Removed Controller\AdminController: the ExtJS-based admin controller providing list, get, create, delete, save, userSearch and roleSearch actions is no longer available.
  • Removed Controller\ConfigController: the ExtJS-based config export/import controller is no longer available. Config import/export is now handled via HyperMDM Studio.
  • Removed Routing\StudioRouteLoader: Studio routes are now registered via standard Symfony configuration.
  • Removed Resources/config/hypermdm/studio_routing.yaml.
  • Admin routing configuration Resources/config/hypermdm/routing.yml has been reduced to Studio-only routes.

Service / Configuration Changes​

  • HyperMDMWorkflowDesignerExtension no longer conditionally loads studio_backend.yaml: it is always loaded.
  • Removed the CSP header exclusion admin path entries from Resources/config/hypermdm/config.yaml.
  • Removed the index.html.twig view previously used as the ExtJS wrapper page.

Internal Service Changes​

  • UserRoleSearchService: Removed is_array() guard around $list->getUsers() and $list->getRoles(): the list methods are now assumed to always return an iterable. Implementations relying on these lists returning null will need to be updated.

Update to Version 1.4​

General​

  • Dropped support of HyperMDM 10, bumped minimum requirement of hypermdm/hypermdm to ^11.2. Replaced all $request->get() with their explicit input source.

HyperMDM Workflow Designer

The Workflow Designer extension provides a visual designer for HyperMDM workflow engine.

Features in a Nutshell​

  • Create one or multiple workflow definitions and organize them in a folder structure.
  • Define workflow places, transitions and global actions with a visual designer and specify all settings inline.
  • Save workflow definitions to configuration files.

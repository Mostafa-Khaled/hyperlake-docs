Workflow Automation Integration

The Workflow Automation Integration bundle exports configuration blueprints for workflow automation engines such as n8n, derived from existing Datahub configurations for GraphQL and Webhooks. Those engines define and execute chains of tasks, which shortens the path to integrating HyperMDM with third-party systems.

Features in a Nutshell​

  • Export workflows based on your Datahub configurations for automation engines like n8n.
  • Download JSON automation blueprints for Datahub GraphQL and Webhook endpoints.
